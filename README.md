### Анализ данных и машинное обучение
`Python` `Scikit-learn` `TensorFlow/Keras` `Pandas` `OpenCV` `NLTK` `Featuretools`

**Учебный проект** (реализован полный цикл разработки ML-решений.

Комплексный проект, демонстрирующий применение алгоритмов машинного и глубокого обучения для решения задач классификации, регрессии, кластеризации и оптимизации. В работе использовались различные типы данных: табличные медицинские данные (Diabetes, Stroke Prediction), текстовые отзывы (Phone Reviews) и наборы изображений (Fruits Dataset).

**Обработка данных и Feature Engineering:**
- очистка данных и импутация пропущенных значений с помощью алгоритма K-ближайших соседей (`KNNImputer`);
- дискретизация (биннинг) непрерывных признаков и One-Hot Encoding категориальных переменных;
- автоматическая генерация новых признаков с использованием библиотек `Featuretools` и `Woodwork` (Deep Feature Synthesis);
- построение `scikit-learn` пайплайнов (`Pipeline`, `ColumnTransformer`) для строгого предотвращения утечки данных (data leakage).

**Классическое машинное обучение и кластеризация:**
- обучение и сравнение моделей: Логистическая регрессия, Random Forest, Gradient Boosting, SVM, Decision Tree;
- автоматический подбор гиперпараметров с помощью `GridSearchCV` и оценка качества по метрикам ROC-AUC, F1-score, Recall;
- сегментация данных методами K-Means и иерархической кластеризации (линковка Уорда);
- понижение размерности (PCA, t-SNE) для визуализации и валидация кластеров (Silhouette Score, Davies-Bouldin Index).

**Глубокое обучение и Computer Vision:**
- разработка и обучение полносвязных (MLP) и сверточных нейронных сетей (CNN) с использованием слоев `Conv2D`, `MaxPooling2D`, `Dropout`, `BatchNormalization`;
- применение Transfer Learning на базе предобученной архитектуры `VGG19` (веса ImageNet) для извлечения признаков и классификации изображений;
- программная аугментация данных (`RandomFlip`, `RandomRotation`, `RandomZoom`) для повышения робастности модели и борьбы с переобучением.

**NLP и эвристическая оптимизация:**
- предобработка текста: токенизация, лемматизация, стемминг, POS-тегирование и работа с N-граммами;
- векторизация текста (Bag of Words, TF-IDF) и применение гребневой регрессии (Ridge) для предсказания рейтинга;
- реализация генетического алгоритма (одноточечный кроссинговер, мутация, рулеточный отбор) для решения задачи комбинаторной оптимизации (составление рациона питания).
